# PDI — GenAI & Agentes

Plano de desenvolvimento individual em GenAI: Python e Streamlit, RAG com
pgVector, agentes com LangChain/LangGraph/MCP e um projeto final de
perguntas e respostas sobre PDFs.

O roteiro completo — itens, entregáveis, prazos e progresso — está em
[PDI_GENAI_CONSOLIDADO.md](PDI_GENAI_CONSOLIDADO.md).

- **Início:** 26/10/2026
- **Entrega:** 13/12/2026 (95h, a 14h por semana)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
