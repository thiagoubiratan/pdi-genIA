checklist:

Tarefa: ponto principal, onde se descreve de forma clara e objetiva o que você quer fazer criar, comparar e.t.c

formato: formato de sair, tipo de arquivo, padrão ou formatacão especifica

público: o nome já diz papel ou pessoa especifica

restricoes: o que não se deve aplicar ou fazer, limites de tamanho (máximo 3 bullets, um paragrafo, e.t.c)

exemplo de prompts:

vago: escreva uma descrição de PR pra mim
especifico: escreva uma descrição de PR pra mim no formato conventional commit, que vai avaliar é o lider tecnico do projeto, em um formato resumido em topicos

o que aprendi:
a forma que se escreve o prompt define a saida(resposta), um prompt bem estruturado se tem um resposta mais especifica, um prompt vago a LLM tenta adivinhar o que vc está esperando.
